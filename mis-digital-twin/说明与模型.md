# MIS 双层超表面数字孪生演示

版本日期：2026-10-05。离线、模型驱动的交互演示；未接入电机、USRP 或其他硬件，也未进行实测校准。

## 打开与讲解

双击同目录的 `启动演示.cmd`，或用 Chrome / Edge 打开 `MIS_3D演示.html`。这是已打包的单文件版本，全部渲染资源内嵌，不需要联网或安装前端依赖，也可单独复制到其他电脑。原始可编辑入口为 `index.html`，使用该入口时需保留完整目录。详细说明和复现脚本在文件夹内。

宽屏默认采用并排演示布局，同时展示 3D 结构、相位图、波束切面和星座图。右上角可以切换到展开讲解布局。窄屏顶部可展开/收起控制参数。

推荐讲解顺序：

1. 选择 **Snell 闭式**，观察两张互补二次相位面；拖动 X/Y 位移，MS 2 整块移动而自身相位不变。
2. 点击 **对准 → 失配 → 恢复**。接收机先在 0° 对准，再移至 30°，最后仅移动 MS 2 恢复链路。每个阶段约 3.5 秒。
3. 切换 **联合优化**，重复同一过程。切换设计保持当前机械位置，点击“选择最佳位置”才针对当前接收方向枚举选位。
4. 点击 **自动演示 9 个目标方向**，观察相位面不变、机械位置和接收方向依次变化。手动操作位移或方向会停止自动演示。
5. 在页面下方比较两种设计的最差方向 SNR，打开优化过程查看真实记录。

3D 支持拖动旋转、滚轮缩放、双击或按钮复位。白色接收方向与数值波束峰值是独立标记。可以关闭波束以看清两层结构。层间距滑块仅放大视觉间隔，不改变计算。相位图白框标记 MS 2 覆盖区域；悬停可以读取单元相位。

通信支持 QPSK、16-QAM、64-QAM，以及均衡前后星座图；参考 SNR 可调。导出按钮保存当前两层相位、等效相位、位置、复信道及指标 JSON。

## 共享计算模型

MS 1 位于 XY 平面，+Z 为出射法向。行优先索引为 `row*n+column`，X 对应列，Y 对应行；相位图上方对应 +Y。

接收方向余弦为

\[
u_x=\sin(\mathrm{az})\cos(\mathrm{el}),\quad
u_y=\sin(\mathrm{el}),\quad
u_z=\cos(\mathrm{az})\cos(\mathrm{el}).
\]

两层固定相位记作 α、β。MS 2 处于位置 u 时：

\[
w_u=e^{j\alpha}\odot(S_u e^{j\beta}+e_u).
\]

**未覆盖区域的第二层系数为 1，不是 0**；因此全部 256 个 MS 1 单元均参与场叠加。重叠处有 144 个单元，未覆盖处有 112 个。

远场复幅度使用固定 MS 1 孔径坐标计算：

\[
F_u(u_x,u_y)=\frac{1}{256}\sum_m w_{u,m}
\exp[-j2\pi(x_m u_x+y_m u_y)/\lambda].
\]

归一化功率 \(|F_u|^2\le1\)。所有图共享理想全孔径相干功率 1 的标尺，不按各自最大值重新归一化。切面图同时显示相同机械位置下的两种方案；九方向比较图则允许两种方案分别选取各方向的最优位置。

3D 波束由 25×37 个方向的实际场计算生成，范围 az/el = ±85°；离散采样峰值仅为显示参考。径向长度使用

\[
r=2+11\,\mathrm{clip}((35+10\log_{10}|F|^2)/35,0,1),
\]

这是 −35…0 dB 的方向图显示映射，不是传播距离或场线。3D 的表面展开、移动插值及入射波示意不参与电磁计算；数值指标对应目标格点的稳态。

## 两套静态设计

### 联合相位与离散选位

论文允许每个目标独立选择一个位置，同一位置可服务多个目标，因而可以精确消去二值调度变量：

\[
\max_{\alpha,\beta}\min_k\max_{u\in\{1,\ldots,25\}}
|F_u(u_{x,k},u_{y,k})|^2.
\]

演示求解器每次评估均精确枚举 25 个位置，使用 log-sum-exp 平滑最差目标、解析相位梯度、L-BFGS/Armijo 更新相位。使用 3 次初始化（包含 Snell 基准）、7 个平滑阶段，并保留当前最佳真实可行目标值。相位参数化保证透射系数单位模。

它求解论文的有限样本目标，但**不是论文原始乘积流形 RCG 的逐行复现，不声称全局最优**。切换目标方向或移动滑块不会在线重设计相位。收敛图为实际接受迭代中的“已找到最佳可行解”，不是凭空生成的曲线。

### Snell 闭式示例

以波长归一化坐标 \(\tilde{x}=x/\lambda\) 等构造：

\[
\alpha(x,y)=+\pi c(\tilde x^2+\tilde y^2),\quad
\beta(\xi,\eta)=-\pi c(\tilde\xi^2+\tilde\eta^2).
\]

MS 2 平移 Δ 后，重叠区的相位为线性梯度加常数：

\[
\alpha(r)+\beta(r-\Delta)
=2\pi c\,\tilde r\cdot\tilde\Delta-\pi c|\tilde\Delta|^2.
\]

所以重叠区的预测方向余弦为 \(u_x=c\Delta_x/\lambda\)、\(u_y=c\Delta_y/\lambda\)。本例取 \(c=1.1745484269437203\)，使单轴位移 ±12 mm 时解析方向为 ±35°。该 c 是指定演示参数，并未对所有可能的 Snell 参数做搜索优化。

由于未覆盖区域仍然辐射，**整个表面的实际主峰不必严格等于这一重叠区解析角度**。程序始终进行全孔径复场叠加，而不是直接把波束画到预测方向上。平面波入射下不需要球面波透镜补偿；若接入近距离馈源，必须同时加入馈源的幅度与相位后重新设计和验证。

## 星座、SNR 与有限帧误差

\[
y=F_us+n,\quad E|s|^2=1,\quad
n\sim\mathcal{CN}(0,10^{-\mathrm{SNRref}_{dB}/10}).
\]

实际接收 SNR 为 `SNRref_dB + 10log10(|F|²)`。均衡视图显示 `y/F`；原始视图显示 y，理想十字标记仍是发射星座。两个方案使用相同符号和原始噪声随机序列。QAM 各轴采用 Gray 编码；EVM 按已知发送符号与理想均衡结果计算，BER 来自本帧实际比特计数。

显示 BER=0 仅表示当前有限帧未观察到比特错误，不代表理论错误概率为零。低 SNR 时，超出固定星座绘图窗口的点数会明确显示。未包含信道估计误差、同步误差、射频失真、多径、OFDM/LTE 协议或真实 IQ 数据。

## 已计算的结果

以下是当前有限模型的实际数值，默认参考 SNR=26 dB：

| 方法 | 九方向最差相干效率 | 效率 dB | 最差接收 SNR |
|---|---:|---:|---:|
| 指定 Snell 二次相位示例 | 0.1961553466 | −7.0739985 | 18.9260015 dB |
| 联合静态相位与选位 | 0.4152461686 | −3.8169437 | 22.1830563 dB |

本例最差目标提升 **3.25705484 dB**。两种方案最终选中的位置恰好相同，按零基索引为 `[5,7,9,10,12,14,15,17,19]`；优化始终考虑了全部选位，但本次提升来自相位配置改善，不能声称最终选位发生了变化。

这个结果不代表论文原型实测提升，也不保证未训练方向的优越性，更不说明联合优化优于所有可能的 Snell 闭式设计。

## 复现与检查

- `data.js`：两层静态相位、配置、各目标/位置功率、调度、历史和来源说明。
- `compute/generate.py`：重新计算闭式相位及离线联合优化。
- `compute/verify.py`：独立标量场重算、相位梯度等验证。
- `compute/reproduce.cmd`：使用本机可用的 Python 与 NumPy 重新生成并验证。
- `compute/validation.json`：19 项数值检查结果。
- `app.js`：共享复场、切面、星座和交互逻辑。
- `scene.js`：本地 Three.js 3D 场景。
- `browser-validation.json`：本次浏览器核验记录。

运行 `compute/reproduce.cmd` 会更新 `data.js` 与计算验证记录；原始入口 `index.html` 随后需要刷新。若要更新单文件版本，再运行 `node bundle.cjs`。可移植的手动复现方式是安装 `compute/requirements.txt` 后运行 `python compute/generate.py` 和 `python compute/verify.py`。

数值检查覆盖：独立复场与导出数据一致、离散 argmax 选位、144/112 重叠计数、未覆盖系数为 1、固定相位不随机械移动变化、归一化上界、Snell 梯度、解析梯度有限差分、最优历史单调性。梯度最大绝对误差约 2.53×10⁻¹²；浏览器与离线全部 450 个功率值最大差约 8.89×10⁻¹⁶。

若用于后续真正的硬件数字孪生，应接入原型制造相位/透射幅度、馈源测量或全波场、电机位置读数和实测 IQ。当前文件提供了模型及数据导出基础，但没有虚构硬件接入。
