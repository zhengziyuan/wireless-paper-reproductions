# Actual native saved-domain prefix supplement

This is a **new domain-only supplement**, not an upgrade of any old false
certificate. It independently reads the actual saved initial/final matrices
from the first 9 completed native MATLAB scenes (108 prescribed starts,
216 initial/final states). Every saved 16-by-16 beam matrix is finite and obeys
the original 100 W total-power gate; every encoded 25-element phase vector
is finite and unit modulus. The original inputs/results and current scientific
source bindings were checked without invoking a model, optimizer, or solver.

Run `python verify_saved_domains.py .` with NumPy installed. The compressed
array bank is derived exactly from actual saved JSON numbers. MATLAB singleton
row/column phase orientation is **not** recovered from that JSON. The original
WORK receipt stem said `native8`; a ninth result completed before the immutable
progress snapshot was read. Both the frozen receipt and manifest correctly
record 9 scenes/108 starts. No old file was renamed or rewritten to hide this.

This evidence does **not** independently certify mean-model QoS, phase-stage
gradients, every convex candidate, native channel/RNG replay, all solver
callbacks/MEX before execution, all 18 scenes/243 starts, or historical figure
agreement. The original files really do contain final W, phase, and no-RIS
flags; they do not contain the required actual mean-input matrices, phase
contexts, convex inputs/candidates, or native RNG/channel states. Those missing
fields cannot be retrospectively manufactured by a recording adapter.

`manifest.json` binds the five frozen data/checker files listed in it and every
original raw input/result digest. This explanatory README was added after the
immutable data manifest and is not one of its bound runtime/data files.
`original_work_auditor.py` preserves the actual original auditing source; its
WORK-relative raw-bank route is historical, not the portable replay command.
All full-reproduction, QoS/gradient/RNG/backend/full18 flags remain false.
