Those parent data/reference files are not copied here.

Full per-component, per-precision and per-scheme values are in the compressed comparison report.

The earlier attempt remains a genuine natural1/sourceclosed host failure. The successful attempt's84 calls must not be described as the total native calls across all attempts. No numerical PASS or failure is assigned to the failed attempt's unsaved output.

These are **new source-bound native derivative evaluations at saved states**, not recovery of historical in-memory analytic vectors. They close the native-vector comparison gap only for the84 own-block entries. They do not validate the five final analytic vectors, change the original producer exit2, repair scheme3/5 strict stopping failures, turn common Python64 fields into historical native captures, or establish final joint KKT. Existing W/strict/joint/reference/full-paper failures and unknowns remain as documented in the parent package. No optimizer, solver update, MC, RNG draw or trial was run for this evidence, and no MP reference was regenerated.
