# Complete paired MIS sensing tail-state replay

This reader covers every original slot 5001–6000 in both saved implementations:
2,000 complete final states and 30,000 original outer records per language.
All original failed outcomes remain in the packet. The original population is
6,000 starts, with 30 outer steps and a 4,000-step inner budget per start.
The retained branch is the supplied corrected-paper product raw-PR solver;
the literal printed diagnostic branch remains a separate experiment.

Run from the repository root with Python 3.12 and the pinned NumPy runtime:

```text
python -m pip install -r tools/sensing-tail-paired-replay/requirements.txt
python -B tools/sensing-tail-paired-replay/replay_packet.py --output-dir /absolute/data/output
```

Use a new output directory. Numerical extraction, fresh fields and reports go
there. The default packet is
`strict/validation/mis-sensing-tail1000-paired-final-state-20261018`.

The cold reader evaluates every final state using independently constructed
binary64 geometry and the unchanged independent Decimal60 final-KKT functions.
It binds the exports to completed MP80/100 physical-reference receipts; it
does not start a new MP reference campaign or an original optimization.
Every actual X argmax is checked against the recorded binary schedule. Fresh
artifacts retain the complete physical intermediates, final gradients,
certificates and original stop decisions for every included state.

The included native initializer arrays support a pure source-contract replay
on all 881,000 primitive uniforms and 1,538,000 initial real coordinates.
This is a reconstruction of the frozen initializer contract. The full actual
historical initial states were not saved. Original inner logs remain bound by
their logical hashes and counts; this packet exports the complete outer
records, rather than the full original inner trajectories or unsaved gradients.

The reported original outcomes are 802 pairs passing in both languages,
76 passing only in MATLAB, 76 passing only in Python and 46 passing in neither.
Each language has 878 original passes and 122 retained failed/unverified slots.
Final values differ. A successful replay verifies the saved exports and
given-model arithmetic; it does not establish matching end-to-end numerical
results, global optimality, original-author normalization, reference curves,
the full 6,000-start native population or all six papers.

The raw-per-PRI echo interpretation, explicit inverse-watt reference and
effective gain 1 are retained. The source's unreported processing/normalization
information remains unresolved. The shared-position bound is conditional on
the retained nonnegative-echo, positive-noise SINR formula.
