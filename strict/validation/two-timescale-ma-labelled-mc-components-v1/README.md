# Labelled fixed-draw ZF: one complete source-D3 component

This packet contains the actual binary input table, portable exact arithmetic,
all3024 complete-leaf intervals and the301 actual prune certificates for
**geometry0, N4/M3, D=3 per axis, all1000 fixed labelled NLoS draws**. Every9
original grid point in[-1.6,1.6]^2 and every feasible labelled layout is retained.
The candidate-set optimum is approximately21.94477578583846bit/s/Hz, with exact
rational lower/upper endpoints saved separately. The original1000 and100 counts
are reconstruction controls, not reported author counts.

This is **not** completion of Figure19's whole D3:18 axis/all100 geometries,
Figure20, MRT search, MATLAB parity, a practical acceleration claim, or recovery
of the historical author brute-force objective. The paper does not uniquely
identify whether its historical search used the statistical expression or
actual fixed-draw mean. This packet explicitly uses the latter; Eq39 is not
substituted for it. Finite-MC antenna permutations are not symmetries.

The frozen table has shape[1000,4,9,3], complex128, little-endian C order. Its
exact bytes preserve each antenna label's Rician channel for each candidate.
Certificates concern this finite binary table and stored binary power/noise,
not exact transcendental evaluation of exp/sqrt. No sampled grid or shortened
MC evaluation is used. The finite table is synthetic, generated by the public
configuration/geometry0 generator; no private manuscript is distributed.

## Run

With NumPy installed, from the repository root:

```text
python strict/validation/two-timescale-ma-labelled-mc-components-v1/run_component.py --verify-frozen
python strict/validation/two-timescale-ma-labelled-mc-components-v1/run_component.py --preflight --output preflight-new.json
python strict/validation/two-timescale-ma-labelled-mc-components-v1/run_component.py --execute --output full-D3-new.json
```

The first command verifies packet hashes, every exact interval dominance and
all3610 prefix upper bounds/all301 prune records. The second re-evaluates12
fixed, predeclared complete layouts, each with all1000 samples, to check portable
binary input decoding and integer arithmetic. It is a component preflight, not
a full rerun. The third freshly evaluates every3024 layouts, without a subset
option. The actual WORK full3024 computation took709seconds; runtime varies.
Each command refuses to overwrite a requested output. No MATLAB is launched.

`mc_labelled_zf_exact_bound_v1.py` is a byte-identical copy of the actual WORK
math helper. Its historical `displayed_interval` function returns rounded
double reporting values, **not** guaranteed outward endpoints. The portable
entry uses exact rational endpoints and explicitly outward-rounded display
values. Integer certificates never use double display values. The helper's old
lower-consistency check is retained unchanged; this packet's separate stronger
audit covers every descendant **upper**, not just its lower endpoint.

## Mathematical certificate

For G=H^H H positive definite, the original equal-power ZF Schur gain is

    s_u=1/[G^-1]uu=min_{v_u=1} v^H G v.

Any stored binary complex v with v_u exactly1 therefore gives an upper gain
sum_label|h_label v|², independently of errors in the optional approximate
inverse used to choose v. At any positive rational b and a=P/(M*noise):

    ln(1+a*s_u) <= ln(1+a*b)-a*b/(1+a*b)
                   + sum_label a/(1+a*b)*|h_label v|².

The row coefficients are summed across **all1000 samples and all users before**
each unassigned label's candidate maximum. Only future mutual spacing may be
relaxed for an upper bound; labels are never interchanged. Every coefficient,
negative constant term and comparison is enclosed by exact outward integer
rounding at Q80. Approximate inverse accuracy is not a proof premise.

Each complete leaf uses exact Hermitian3x3 integer determinants/minors. Its
logarithms are enclosed by rational range reduction x=2^k*t,1<=t<2 and
z=(t-1)/(t+1)<=1/3. The24-term atanh series has nonnegative tail bounded by
9/(4*49*3^49). Fixed-point multiplications/divisions are rounded outwards;
ln2 uses the same enclosure. The common positive1000*ln2 divisor is omitted
only during natural-log comparisons, and retained in rational rate endpoints.

The actual single-anchor tree visited3574 nodes, evaluated2693 complete leaves
and pruned301 subtrees. A separate actual read-only audit recomputed every3610
feasible prefix bound and checked it against every exact descendant leaf upper
endpoint. All passed, minimum Q80 integer margin7542. Every actual prune also
has every descendant leaf upper strictly below the incumbent lower. The entire
3024-leaf oracle was used for this component validation, so these node counts
are not a standalone acceleration benchmark. The source/raw hashes bind the
actual all-leaf execution, stronger audit and this packet; no old result is
rewritten or weak check relabelled.
