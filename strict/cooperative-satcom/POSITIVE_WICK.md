# Stable evaluation of the original MR phase objective

The original conditional channel is unchanged:
`h | r ~ CN(d + A r, (dv + gv ||r||²) I)`, where `A=Gmean diag(phi)` and
`r~CN(r0,rv I)`. The cascaded Gaussian product remains non-Gaussian. This is
an evaluation repair, not a replacement of the original QT/RGD algorithms.

The previous phase evaluator formed the TTS own interference as
`E||h||⁴ - (E||h||²)²` and subtracted their derivatives. At two saved full-size
points this lost enough precision near stationarity to fail the independent
gradient comparison. The production phase evaluator now forms the same
variance and its derivative directly. All other objective terms, the squared
interference residual penalty, smoothing schedule, phase radii, search rule,
iteration budgets and strict gradient threshold are retained.

Write `m=d+A r0`, `Cb=rv A A^H`, `Ev=dv+gv E||r||²` and
`T=A^H A+N gv I`. The own variance is the sum of:

- `rv² ||T||F² + 2 rv ||A^H m + N gv r0||²`;
- `N E[(dv+gv||r||²)²] + 2 dv E||d+A r||²`;
- `2 gv E[||r||² ||d+A r||²]`.

The last expectation uses the positive Wick expansion
`||r0 m^H + rv A^H||F² + M rv ||m||² + rv ||r0||² ||A||F² + M rv² ||A||F²`.
The full mean/covariance cross terms and exact angular derivatives remain
present. Stable finite-sum accumulation changes rounding, not the model.

The hand-solvable scalar test has `d~CN(0,4)`, `G~CN(1,2)` and `r~CN(0,3)`.
It gives second moment13, fourth moment482 and own variance313. A Gaussian
replacement would incorrectly give fourth moment338. Both languages check
the exact scalar result; the original full-size derivative and increment
checks also pass.

[The actual saved-endpoint packet](../validation/cooperative-positive-wick-20261017/README.md)
contains all91 original endpoint inputs, retained MP80 references and actual
MATLAB outputs. Every one of8190 complex gradient components in each language
passes the original `1e-9 + 1e-10*abs(reference)` allowance; every complete
gradient passes strict norm `<1e-6`. The source/configuration bindings now
include the new arithmetic provider. Old receipts remain unchanged and
cannot be resumed as if they were generated by this changed source.

This repair covers MR phase evaluation. Independent complete native figure
execution, other native solver failures and historical reference agreement
remain separate requirements.
